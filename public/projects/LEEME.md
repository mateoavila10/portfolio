# Capturas de proyectos

Guardá acá las capturas de cada proyecto (idealmente `.webp` o `.jpg`, 1600×1000 px, proporción 16:10).

Después, en `src/data/projects.js`, completá el campo `image` del proyecto:

```js
image: '/projects/padel-saas.webp',
```

Mientras `image` esté vacío se muestra `placeholder.svg`.

Ojo con los proyectos privados: antes de subir una captura, revisá que no se vean datos reales de personas, clubes, montos ni claves.
